# Stars2D Screensaver

An Android screensaver app featuring smooth, GPU-accelerated starfield animations using **OpenGL ES 2.0**. Creates immersive parallax effects with layered star rendering for a realistic "flying through space" experience.

## Overview

Stars2D Screensaver is a lightweight Android screensaver that activates while the device is charging. It utilizes OpenGL ES for hardware-accelerated graphics rendering and provides a charge-end notification system with haptic feedback.

## Technical Stack

- **Language:** Kotlin
- **Graphics API:** OpenGL ES 2.0
- **Minimum SDK:** 23 (Android 6.0)

## Features

- OpenGL ES 2.0 parallax starfield rendering
- Configurable star size and density
- Charge-end detection with vibration + audio notification
- Layered star rendering with variable speeds for depth effect
